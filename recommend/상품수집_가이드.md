# 실제 상품 데이터 수집 (3명 × 50개 = 150개)

네이버 쇼핑 검색 API가 2026년 7월 31일에 종료돼서, 실제 상품은 팀원이 직접 모은다.
양식: **`recommend/data/collect/상품수집_양식.xlsx`** (시트: 쓰는 법 / 팀원1 / 팀원2 / 팀원3)

## 하는 일 (복사해서 붙여 넣기만)

1. 내 시트를 연다. 줄마다 **번호와 "찾을 옷"이 이미 적혀 있다**
2. 그 옷을 쇼핑몰에서 하나 찾아서 붙여 넣는다
   - 상품명, 가격(숫자만)
   - 상품 링크 (주소창 주소)
   - 사진 주소 (대표 사진 오른쪽 클릭 → "이미지 주소 복사", 안 되면 비우기)
   - 상품 설명 (상세 페이지의 핏·소재·사이즈 설명 부분 복사)
3. 50줄 다 채우면 파일을 서연에게 보낸다

핏·기장·소재·계절 같은 건 **안 쓴다**. 붙여 넣은 상품 설명을 보고 서연이 자동으로 채운다 (B 파트 태그 규칙).

## 지킬 것

- 여성 의류, 지금 판매 중인 국내 상품만 (품절·해외직구·중고 X)
- 색만 다른 같은 상품은 1개
- 사진 파일은 저장하지 않는다 (주소만). 수업 시연용으로만 쓰고 발표 자료에 "상품 사진 출처: 각 쇼핑몰(시연용)"을 적는다
- 가능하면 가을·겨울 옷 위주로, 가격대는 골고루

## 서연이 하는 일 (받은 뒤)

상품 설명에서 핏·기장·실루엣·허리선·소재·장식·계절을 뽑아 태그(`data/tag_weight.json`의 `fit:slim`·`len:crop`·`sil:wide` …)를 붙이고, 확인한 뒤 Supabase에 넣는다.
태그가 하나도 없는 상품은 추천에서 빠지므로(`exclude_no_info`), 설명에 핏·소재가 없는 상품은 다른 상품으로 바꿔 달라고 한다.
