# 실제 상품 데이터 수집 가이드 (3명 × 50개 = 150개)

네이버 쇼핑 검색 API가 2026년 7월 31일에 종료돼서, 실제 상품은 팀원이 직접 모은다.
모은 표는 나중에 `recommend/import_products.py`(만들 예정)로 태그를 붙여 Supabase DB에 넣는다.

## 0. 공통 규칙

- **여성 의류만** (앱 가입 성별이 여성만, 골격 기준 논문도 여성 대상)
- 국내 쇼핑몰의 **실제 판매 중인 상품**. 품절·해외직구·중고 제외
- **같은 상품의 색만 다른 것은 1개**로 친다 (색은 `색상` 칸에 여러 개 적기)
- **사진은 복사하지 않는다** (저작권). 상품 링크만 적는다
- `상세설명`에는 **핏·기장·소재가 적힌 부분만** 짧게 복사 (전체 복사 X)
- 판단이 어려우면 `모름`이라고 쓰고 `메모`에 이유를 적는다. 추측해서 채우지 않는다
- **계절 비율**: 각자 50개 중 대략 가을·겨울 30개, 봄 10개, 여름 10개 (지금이 11월이라 가을·겨울을 많이)
- 가격대도 섞기: 3만 원 이하 / 3~7만 원 / 7만 원 이상이 골고루

## 2. 표에 넣을 칸 (양식: `recommend/data/collect/팀원N_….csv`)

한 줄 = 상품 하나. 양식 파일 첫 줄의 칸 이름과 순서를 바꾸지 않는다. 예시 줄은 지우고 쓴다.

| 칸 | 쓰는 법 | 고를 수 있는 값 |
|---|---|---|
| 번호 | 위의 번호 범위 | U001, B012, O003, D020 … |
| 수집자 | 이름 | |
| 종류 | 영어로 | `top` `pants` `skirt` `outer` `dress` |
| 세부종류 | 자유롭게 (아래 두 개는 정확히) | 니트, 셔츠, 슬랙스 … / **`테일러드재킷`** / **`타이트스커트`** |
| 상품명 | 쇼핑몰에 적힌 그대로 | |
| 브랜드 | | |
| 가격 | 정상 판매가, 원 단위 숫자만 (쉼표·원 빼기) | 39000 |
| 상품링크 | 상품 페이지 주소 | |
| 핏 | 상세에 적힌 핏 | `슬림` `기본` `오버` `모름` |
| 기장 | | `크롭`(허리선 위) `기본` `롱`(상의는 엉덩이 아래, 하의는 발목, 스커트·원피스는 종아리 아래) |
| 실루엣 | 하의·원피스 위주. 상의는 보통 `없음` | `일자·H` `A라인` `와이드` `스키니` `없음` |
| 허리 | 하의·원피스만 | `하이` `기본` `없음` |
| 주소재 | 혼용률에서 가장 많은 것(50% 이상). 없으면 `기타` | `면` `데님` `실크` `시폰` `린넨` `울` `니트` `가죽` `나일론` `퍼` `캐시미어` `벨벳` `코듀로이` `무스탕` `모헤어` `기타` |
| 장식 | | `러플` `리본` `없음` |
| 계절 | 여러 개면 `;`로 | `봄` `여름` `가을` `겨울` → 예) `가을;겨울` |
| 사이즈 | `;`로 | S;M;L 또는 FREE |
| 색상 | `;`로 | 블랙;아이보리 |
| 상세설명 | 핏·기장·소재 부분만 | "울 60% 폴리 40%, 허리선 위 크롭" |
| 메모 | 애매했던 점 | |

**소재 팁**: 니트 상품이 울 70%면 `주소재`=`울`로 쓰고, 상세설명에 "니트"가 남아 있으면 스크립트가 니트 태그도 같이 붙인다. 모헤어가 30%만 들어가도 상세설명에 적어 두면 모헤어 태그가 붙는다.

## 3. 저장·제출

1. 양식 CSV를 엑셀이나 구글 시트로 연다 (구글 시트 하나에 탭 3개를 만들어 같이 써도 된다)
2. 다 쓰면 **CSV UTF-8(쉼표로 분리)** 형식으로 저장한다 (엑셀의 그냥 "CSV"는 한글이 깨질 수 있다)
3. 파일 이름은 그대로 두고 `recommend/data/collect/`에 덮어쓴 뒤 각자 브랜치에 올린다
4. 서연이 `develop`에서 합치고 DB에 넣는다

## 4. 왜 이렇게 나눴나

- 추천 점수는 상품의 **태그**로 계산한다 (B 파트 `data/tag_weight.json`, 26개). 이 표의 핏·기장·실루엣·소재·장식·세부종류가 그 태그가 된다
  - 예: 슬림 → `fit:slim`(S+2), 크롭 → `len:crop`(W+2), 와이드 → `sil:wide`(N+2), 일자·H → `sil:IH`(S+2), A라인 → `sil:A`(W+2), 러플 → `det:ruffle`(W+2), 린넨 → `mat:linen`(N+2), 테일러드재킷 → `item:tailored_jacket`(S+2)
- 코디 점수에는 `허리`=하이(`waist:high`, 웨이브 크롭 상의와 궁합), `실루엣`=스키니(`sil:skinny`)도 쓴다
- 태그가 하나도 없는 상품은 추천에서 빠지므로(`exclude_no_info`), 핏·소재를 꼭 채운다
