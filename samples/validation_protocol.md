# 새 상품 검증 규칙 (결과를 보기 전에 정함, 2026-10-11)

- 규칙 고정: 이 시점의 matching.py·data/*.json (65→67개 테스트 통과 버전). 검증 중 규칙을 고치면 고치기 전 결과를 reports에 그대로 남기고, 고친 뒤 결과는 따로 적는다.
- 대상: 무신사 여성 상품 20개 = 상의 7 + 하의 7 + 아우터 6. 원피스·세트·액세서리는 제외.
- 선정: 카테고리 랭킹 목록을 위에서부터 훑어, 기존 96개(samples/musinsa_96.json)와 시연 36개에 없는 상품을 순서대로 채택한다. 설명이 글인지 이미지인지, 태그가 잘 붙을지는 보지 않는다. 건너뛰는 경우는 상세 정보를 못 받은 상품(API 오류), 품절로 정보가 없는 상품뿐이고 건너뛴 id와 이유를 기록한다.
- 정답: 판매자 핏(goodsMaterial.materials의 '핏')이 있는 상품만 핏 비교에 쓴다. 소재는 혼용률 문구가 있는 상품만 대조한다.
- 보고: 핏은 정확 일치 / 미분류 / 동의어 누락 / 오분류로 나눠 세고, 실패 상품도 모두 싣는다. 설명이 글인 것과 이미지인 것을 따로 센다.
- 이미지 설명 상품은 tools/vision_experiment.py 로 글을 읽은 결과를 쓴다 (읽기 실패도 기록).
