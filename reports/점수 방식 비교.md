# 점수 방식 비교 (시험판, 운영 코드 변경 없음)

`tools/score_variants.py`로 재현. 비교 대상: ① 현재(태그 평균) ② 그룹 묶기 ③ 회피 감점 ④ 그룹+감점. 데이터는 격자 588개와 실제 50개(`real_50_tags_20261012.json`), 프로필은 A 출력 7종.

## 방식
- **그룹 묶기**: 태그를 속성 그룹(fit·len·sil·mat·det, item은 fit에 포함)으로 묶고 그룹 안에서는 평균 → 그룹 값끼리 평균. 같은 속성이 여러 태그로 중복되는 것을 막는다.
- **회피 감점**: 그룹(또는 태그) 값이 음수면 평균과 별도로 `κ × 음수 합 / 가중치 범위`만큼 추가로 뺀다(상쇄되지 않고 태그 수로 희석되지 않음). κ=0.5.

## 예시 (pure_S)
| 태그 | 현재 | 그룹 | 감점 | 그룹+감점 |
|---|---|---|---|---|
| slim + ruffle | .444 | .444 | .278 | .278 |
| slim + ruffle + long | .333 | .333 | 0.000 | 0.000 |
| cotton | .500 | .500 | .500 | .500 |
| (태그 없음) | .333 | .333 | .333 | .333 |
| slim + tight_skirt + IH | .833 | .778 | .833 | .778 |
| slim + cotton + wool | .583 | .611 | .583 | .611 |

## 실제 50개: 상위 10위 안에 '1위 유형이 피해야 할 태그가 붙은 상품' 수 (현재 → 감점)
S_W 2→0, pure_S 1→0, pure_W 3→0, 나머지는 변화 없음. W_N은 3개가 κ=1까지 그대로 남는다(W에는 피해야 할 태그가 N에는 좋은 태그라 혼합 점수가 양수). 설계상 맞는 동작이지만 "혼합형에서 1위 유형의 회피 태그를 어디까지 허용하나"는 팀 결정이 필요하다.
- 현재와 상위 10 겹침: 감점 7~10개, 그룹 묶기 6~10개(격자 N_S는 6개). 순위상관 0.83~1.00.

## 발견한 문제 / 한계
1. **감점이 0점으로 잘려 동점이 생김**: pure_S 격자 94/588, 실제 pure_W 10/50. 가장 나쁜 쪽이라 해는 작지만, 구현 시 정규화 범위를 넓혀 잘림을 없애야 한다.
2. **그룹 묶기는 순위를 바꾸지만 어느 쪽이 더 맞는지 판단할 정답이 없음**: 근거는 "같은 속성 중복 방지"라는 원칙뿐. 두 사람 라벨이 있는 상품 세트에서 따로 확인해야 한다.
3. **정보 없는 상품의 위치는 해결 안 됨**: 실제 50개에서 pure_W 사용자는 무정보 상품이 평균 상위 38%(회피 상품은 69%)에 놓이고 pure_N은 88%. 유형별 정규화 문제로 남는다.
4. κ=0.5는 임의값. κ 0.25~1에서 실제 50개 결과는 거의 같아 민감하지 않다.
