# 상품 정보 입력 가이드 (팀 입력용)

외부 쇼핑몰 상품을 판매자 등록 양식(`data/attributes.json`)과 같은 항목으로 직접 입력할 때의 기준이다. 입력한 상품은 `source="manual"`로 넣는다.

## 원칙
1. 근거가 있는 값만 넣는다. 상품 설명 문구, 사이즈표, 혼용률 표기처럼 확인할 수 있는 것을 근거로 한다. 모델 사진을 보고 느낀 인상만으로 핏을 고르지 않는다.
2. 근거를 못 찾으면 비워 두거나 "확인 불가"를 고른다. 추측해서 채우지 않는다.
3. 입력 한 줄마다 근거를 적는다: 어디서 확인했는지(예: 설명 3번째 줄, 사이즈표, 혼용률 표).
4. 입력자 이름과 입력일을 기록한다. 같은 상품을 두 명이 따로 입력해 서로 비교하는 표본(20~30개)을 만든다.

## 항목별 기준
| 항목 | 근거로 인정하는 것 | 근거가 없을 때 |
|---|---|---|
| 핏 (필수) | 설명의 "슬림핏/레귤러핏/오버핏/루즈핏" 표기. 판매자가 직접 쓴 문구여야 한다. | 필수 항목이라 비울 수 없다. 단서가 없으면 해당 상품은 입력 대상에서 제외하고 목록에 사유를 남긴다. |
| 기장 (필수) | 설명에 명시된 기장 표현("크롭", "롱" 등)만 쓴다. 총장 수치(cm)만 있는 상품은 어느 길이로 볼지 기준을 아직 정하지 않았으므로 판단을 보류한다. | 같은 방식으로 제외하고 사유("총장 수치만 있음" 등)를 남긴다. |
| 실루엣 (선택) | 설명의 "와이드", "스트레이트", "A라인", "스키니" 표기 | 비워 둔다 |
| 허리 (선택) | "하이웨이스트" 등 설명 표기 | 비워 둔다 |
| 디테일 (선택) | 설명의 "러플", "프릴", "리본" | 비워 둔다 |
| 소재 (선택) | 설명의 "니트", "데님", "가죽"처럼 소재로 쓰인 표기. 가죽 패치·라벨 같은 장식 부위는 소재가 아니다. | 비워 둔다 |
| 혼용률 (필수) | 혼용률 표기. 겉감과 안감이 나뉘면 겉감 값을 쓴다. 합계는 100%여야 한다. | "확인 불가" 또는 "해당 없음" |
| 종류 (선택) | "테일러드 재킷", "타이트 스커트", "모헤어 니트", "롱 카디건", "크롭 팬츠" 등 상품 종류 표기 | 비워 둔다 |

## 비워 둔 선택 항목은 글에서 보충된다
비운 선택 항목(실루엣·허리·디테일·소재·종류)은 상품명과 설명(`desc`)에서 자동으로 보충된다(`text_added`로 구분). `desc`를 비워도 상품명에서는 읽는다. 자동 보충을 끄려면 상품에 `"text_fill": false`를 넣는다. 핏·기장·혼용률은 항상 입력한 값만 쓴다. "해당 없음"을 고른 항목은 비운 것이 아니라 없다고 입력한 것이므로 글로 보충하지 않는다. 실루엣·디테일·소재·종류는 해당 사항이 없으면 비워 두지 말고 "해당 없음"을 고른다.

## 헷갈리기 쉬운 경우
- 설명에는 오버핏이라 쓰여 있는데 쇼핑몰 필터의 핏 값은 레귤러: 판매자 설명 문구를 쓰고 모순이 있었다고 메모한다.
- 케어라벨 범례표("핏 | 슬림핏 | 기본핏 | 루즈핏/오버핏 | 와이드핏")는 그 상품의 핏이 아니다. 범례 중 어느 칸이 표시됐는지 이미지로 확인되면 그 칸을 쓰고, 안 되면 근거로 쓰지 않는다.
- 반품·교환 안내문의 문장(예: "천연가죽 제품의 경우")은 상품 소재 근거가 아니다.
- "세미 오버핏"은 오버핏이 아니다. 레귤러 표기가 따로 없으면 근거 부족으로 본다.
- 한 상품에 여러 색상이 있으면 색상별로 따로 입력하지 않고 상품 하나로 입력한다(같은 상품 id).

## 입력 형식
```
{"item_id": 101, "category": "top", "name": "...", "source": "manual",
 "attrs": {"category": "top", "fit": "슬림", "length_top": "기본",
           "composition": [{"fiber": "cotton", "share": 0.6}, {"fiber": "polyester", "share": 0.4}]}}
```
혼용률을 퍼센트(0~100)로 받은 경우 `matching.percent_to_share()`로 비율(0~1)로 바꿔서 넣는다. 양식 검증을 통과하지 못하면 `ValueError`로 어떤 항목이 문제인지 알려준다.
