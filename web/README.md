# 신체 치수 측정 웹 테스트 (아이폰용)

안드로이드 앱의 "카메라로 치수 재기"를 아이폰 Safari에서 테스트하기 위한 웹 버전이다.
키 입력 → 정면 자동 촬영 → 측면 자동 촬영 → 치수 결과까지만 있다. 추천·장바구니 등은 없다.

## 1. 테스트하는 사람 (아이폰)

1. 팀에서 공유한 **https 주소**를 Safari로 연다. (카톡 링크를 눌러도 된다)
   - 주소가 `http://`로 시작하면 카메라가 안 켜진다. 반드시 `https://`.
2. 처음 열면 모델을 받느라 몇 초 걸린다. 버튼이 **"측정 시작"** 으로 바뀌면 준비 끝.
3. 키(cm)를 입력하고 **측정 시작** → 카메라 권한 **허용**.
4. 폰을 벽에 세워 두거나 거치하고, 전신이 다 보이게 2~3m 떨어져 선다.
   - 화면의 초록 가이드(사람 모양)에 몸을 맞추면 **바로 자동 촬영**된다.
5. 사진 확인 창에서 **사진 사용하기**.
6. "측면 촬영 시작"을 누르고, 오른쪽을 보도록 몸을 돌린다. 3초 뒤부터 자동 촬영.
7. 결과 화면에서 치수를 확인한다.

팁: 몸에 붙는 옷, 단색 배경, 밝은 곳일수록 정확하다. 폰은 세로로, 흔들리지 않게.

### 안 될 때
| 증상 | 확인 |
|---|---|
| 카메라가 안 켜진다 | 주소가 https인지. 설정 > Safari > 카메라 > "허용" 또는 "묻기". 이미 거부했다면 주소창 왼쪽 `aA` > 웹사이트 설정 > 카메라 > 허용 |
| "모델 불러오기 실패" | 인터넷 연결 확인 후 새로고침. 앱·VPN·콘텐츠 차단기가 CDN을 막는 경우도 있다 |
| 흰 골격이 몸과 안 맞는다 | 전면/후면 카메라 중 어느 쪽인지, 화면 캡처와 함께 공유 |
| 촬영이 안 된다 | 전신(머리~발목)이 다 나오는지, 가이드와 너무 어긋나지 않는지 |
| 화면이 멈춘다 | 새로고침. 다른 탭·앱을 닫고 다시 시도 |

버그를 알릴 때는 **아이폰 기종, iOS 버전, 전면/후면, 화면 캡처**를 같이 보내 주세요.

## 2. 배포하는 사람 (PC)

아이폰 카메라는 https에서만 켜지므로, 이 `web/` 폴더를 https로 열어 줘야 한다.
빌드 과정은 없다. 파일 3개(`index.html`, `app.js`, `style.css`)가 전부다.

### 방법 A. Netlify Drop (가장 쉬움)
1. https://app.netlify.com/drop 접속
2. `web` 폴더를 통째로 끌어다 놓는다.
3. 나온 `https://...netlify.app` 주소를 팀에 공유한다.
   - 로그인 없이 올리면 일정 시간 뒤 사라질 수 있다. 계속 쓰려면 계정으로 로그인해서 올린다.

### 방법 B. 내 PC에서 임시로 열기 (ngrok)
```bash
cd web
python -m http.server 8000
```
다른 터미널에서
```bash
ngrok http 8000
```
나온 `https://...ngrok-free.app` 주소를 공유한다. PC가 켜져 있는 동안만 열린다.

### 방법 C. GitHub Pages
Pages는 저장소 루트나 `docs/` 폴더만 배포할 수 있다. `web/` 내용을 `docs/`로 복사해서 쓰거나, GitHub Actions로 `web/`을 배포한다.

## 3. 참고

- 관절 인식·윤곽 분리 모델과 라이브러리는 실행할 때 인터넷(jsdelivr, Google 저장소)에서 받는다.
- 계산식은 앱(`BodyMeasurementCalculator`, `BodyMeasurementActivity`, `CircumferenceCalculator`)과 같다.
- 사진은 서버로 보내지 않는다. 폰 안에서만 처리된다.
- 관절 신뢰도 기준이 까다로워 인식이 안 되면 `app.js`의 `MIN_LIKELIHOOD`, `VALID_LIKELIHOOD`를 낮춘다.
