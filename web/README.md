# 신체 치수 측정 웹 테스트

정면·옆면 전신 사진을 올리면 신체 치수(길이·둘레)를 추정하는 웹 버전이다.
키 입력 → 정면·옆면 사진 선택 → 치수 결과까지만 있다. 추천·장바구니 등은 없다.
실시간 카메라 촬영은 없다(2026-10 결정). 사진은 사용자가 안내대로 찍어서 올리고, 올린 사진은 분석 뒤 가볍게 점검해서 경고만 보여 준다.

## 1. 테스트하는 사람

1. 팀에서 공유한 주소를 연다. (카톡 링크를 눌러도 된다)
2. 처음 열면 모델을 받느라 몇 초 걸린다. "모델을 불러오는 중이에요…"가 사라지면 준비 끝.
3. 키(cm)를 입력하고, **정면 사진**과 **옆면 사진**을 선택한다. (폰에서는 사진 보관함이나 카메라로 바로 찍어서 고를 수 있다)
   - **몸무게(kg)와 나이는 선택**이다. 몸무게를 넣으면 결과 화면 아래에 "키·몸무게 기반 추정 (참고)"이 사진 결과와 나란히 나온다. 나이도 넣으면 허리가 조금 더 정확해진다.
   - 이 추정은 사진과 별개로, 20~79세 여성 499명의 실측(AI Hub 「한국인 전신 형상 및 치수 측정」)으로 맞춘 키·몸무게(·나이) 일차식이다. 평균 체형을 가정한 값이라 사람마다 다르고, 사진 결과와 많이 다른 항목은 주황색으로 표시한다. 서비스는 여성만 받으므로 여성 데이터만 쓴다.
   - 몸무게와 나이는 서버로 보내지 않고 기기 안에서만 계산한다.
4. **분석하기**를 누르고 결과 화면에서 치수를 확인한다.
   - 결과 위에 노란 경고가 뜨면, 그 사진의 문제(몸이 작음, 머리·발 잘림, 어깨선 기울어짐, 정면/옆면이 뒤바뀜)를 알려 주는 것이다. 막지는 않는다.
   - "윤곽·측정 위치" 그림에서 초록(몸으로 인식한 부분)에 팔이 섞였는지, 선(노랑 가슴·빨강 허리·파랑 골반)이 맞는 높이인지 확인한다.

### 사진 찍는 방법 (정확도에 큰 영향)
- 머리부터 발끝까지 **전신**이 나오게, 몸이 사진 높이의 70% 이상이 되도록 2~3m 거리에서 찍는다.
- 폰을 **세로로 똑바로** 세우고 가슴 높이쯤에 둔다. 위나 아래로 기울이지 않는다.
- **정면**: 팔을 몸에서 조금(약 30°) 띄우고 똑바로 선다.
- **옆면**: 오른쪽을 보고 서서 팔은 몸 옆에 내린다.
- **몸에 붙는 옷**, 단색 배경, 밝은 곳이 가장 정확하다. 헐렁하거나 어두운 옷은 실제보다 크게(특히 허리) 나온다.
- 정면과 옆면은 같은 거리·같은 높이에서 찍는다.

### 안 될 때
| 증상 | 확인 |
|---|---|
| "모델 불러오기 실패" | 인터넷 연결 확인 후 새로고침. 앱·VPN·콘텐츠 차단기가 CDN을 막는 경우도 있다 |
| "관절 분석 실패" | 전신(머리~발끝)이 나온 사진인지, 몸이 너무 작지 않은지 확인하고 다른 사진으로 시도 |
| 초록 윤곽에 배경 물건이 섞인다 | 단색 배경에서 다시 찍기 |
| 허리·골반이 실제보다 많이 크다 | 몸에 붙는 옷을 입고 다시 찍기 |
| 화면이 멈춘다 | 새로고침. 다른 탭·앱을 닫고 다시 시도 |

버그를 알릴 때는 **기기 기종, OS 버전, 올린 사진(가능하면), 화면 캡처**를 같이 보내 주세요.

## 2. 배포하는 사람 (PC)

사진 등록은 카메라 권한이 필요 없어서 http에서도 동작하지만, 폰에서 열려면 아래 방법처럼 외부에서 접속할 수 있는 주소가 필요하다.
빌드 과정은 없다. 파일 3개(`index.html`, `app.js`, `style.css`)가 전부다.

### 방법 A. Netlify Drop (가장 쉬움)
1. https://app.netlify.com/drop 접속
2. `web` 폴더를 통째로 끌어다 놓는다.
3. 나온 `https://...netlify.app` 주소를 팀에 공유한다.
   - 로그인 없이 올리면 일정 시간 뒤 사라질 수 있다. 계속 쓰려면 계정으로 로그인해서 올린다.

### 방법 B. 내 PC에서 임시로 열기 (ngrok)
```bash
cd web
python -m http.server 8000
```
다른 터미널에서
```bash
ngrok http 8000
```
나온 `https://...ngrok-free.app` 주소를 공유한다. PC가 켜져 있는 동안만 열린다.

### 방법 C. GitHub Pages
Pages는 저장소 루트나 `docs/` 폴더만 배포할 수 있다. `web/` 내용을 `docs/`로 복사해서 쓰거나, GitHub Actions로 `web/`을 배포한다.

## 3. 참고

- 관절 인식·윤곽 분리 모델과 라이브러리는 실행할 때 인터넷(jsdelivr, Google 저장소)에서 받는다.
- 길이 계산은 앱(`BodyMeasurementCalculator`, `CircumferenceCalculator`)과 같고, 윤곽·팔 제외·허리/골반 위치 탐색은 `training/features.py`와 같다. 바꾸면 둘 다 바꾼다.
- 사진은 서버로 보내지 않는다. 기기 안에서만 처리된다.
- 사진 점검 기준은 `app.js`의 `photoWarnings` 함수에 있다(몸 크기 65%, 머리·발 여백, 어깨선 기울기 5° 등).
- 키·몸무게 추정의 계수는 `app.js`의 `PRIOR_COEF`에 있고 `training/export_prior_coef.py`가 만든다. 데이터가 바뀌면 그 스크립트로 다시 만들어 붙인다.
- 가슴 둘레는 타원 둘레에 `CHEST_ELLIPSE_FACTOR`(여성 1.075)를 곱한다. 근거는 사이즈코리아 8차 20대 여성의 가슴 너비·두께·둘레 중앙값이다.
